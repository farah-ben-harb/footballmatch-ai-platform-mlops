# v0.1.0 Release Checklist

## Required evidence before tagging

- [x] Phase 3 and 4 PRs merged to `main`.
- [ ] Compose starts API, MLflow, and PostgreSQL on the local Docker Desktop/WSL2 host.
- [ ] `docker compose ps` and API health evidence captured.
- [x] GitHub Actions workflow is green on `main`.
- [x] Azure Container Apps demo health, readiness, metrics, and end-to-end inference evidence captured.
- [ ] K3s node capacity audited and installation evidence captured.
- [ ] Helm release is deployed and probes are healthy.
- [ ] Prometheus targets and Grafana dashboard screenshots captured.
- [ ] Argo CD application is synced; drift and rollback are demonstrated.
- [x] No secrets, media, weights, or artifacts appear in `git status`.
- [x] README claims match verified reality.

## Portfolio evidence to capture

- MLflow experiment comparison and run artifact view.
- `POST /analyze` then completed job response.
- GitHub Actions green jobs.
- Compose service status.
- K3s pods, PVC, Service, and Helm release status.
- Prometheus target health and Grafana dashboard.
- Argo CD synced application and Git commit revision.

## Release command after all checks

```bash
git checkout main
git pull --ff-only
git tag -a v0.1.0 -m "FootballMatch AI Platform MVP"
git push origin v0.1.0
```

Do not tag before all mandatory evidence exists.
